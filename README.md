# ForgeFuel
ForgeFul is a responsive, self-hosted fitness and nutrition tracker.It combines workout logging with a food pantry and automatic nutrition calculations.
## Features
- Switch between Dashboard, Gym and Kitchen pages
- Record exercises, weights, sets and reps
- Delete saved workouts
- Calculate nutrition based on food weight in grams
- Save and delete pantry items 
- View wokrout, pnatry and calorie totals
- Keep data afer refreshing with localStorage
- Responsive desing for desktop and mobile

## Built with
- HTML
- CSS
- JavaScript
- Browser localStorage
## How to run
1. Download or clone this repository
2. Open the project in Visual Studio COde
3. Open `index.html` with Live server
4. Your data will be stored locally in your browser

## Privacy
Forgefuel stores workout and food data directly in the user's browser. The current version does not send personal data to an external server.
